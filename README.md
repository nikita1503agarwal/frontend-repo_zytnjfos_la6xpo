# Adaptive Tic-Tac-Toe (Frontend)

Interactive UI to play Tic-Tac-Toe against an AI that adapts over time. It connects to the backend API to compute moves and to run a Genetic Algorithm for training.

Features:
- Play as X or O; AI uses alpha-beta minimax.
- Displays performance metrics (time, memory, nodes) per AI move.
- Visualizes top-level decision tree scores.
- Train using GA and view generation stats and best strategy.

Use the System Test page to verify backend/database connectivity.
